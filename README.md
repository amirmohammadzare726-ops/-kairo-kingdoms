# کایرو کینگدامز | Kairo Kingdoms

پروژه مستقل بازی استراتژیک فانتزی سه‌بعدی.

## فناوری‌ها
- Vite
- Three.js
- JavaScript
- رابط فارسی راست‌به‌چپ و واکنش‌گرا

## اجرای محلی
```bash
npm install
npm run dev
```

برای ساخت نسخه انتشار:
```bash
npm run build
npm run preview
```

## وضعیت توسعه
- [x] صحنه سه‌بعدی و چرخش نقشه
- [x] جزایر، کوهستان، جنگل و شهرک‌های قابل انتخاب
- [x] رابط فرماندهی قلمرو و نمایش منابع
- [x] ارتقای آزمایشی ساختمان‌ها و دریافت منابع
- [ ] ذخیره‌سازی پایدار و اتصال به حساب بازیکن
- [ ] سرور بازی، چندنفره و همگام‌سازی جهان
- [ ] سیستم واقعی اقتصاد، ساخت‌وساز و نبرد

**توجه:** فعلاً منابع و ارتقای ساختمان‌ها فقط در حافظه مرورگر و همان نشست آزمایشی هستند؛ هنوز به سرور یا پایگاه داده متصل نشده‌اند. این مخزن پروژه مستقل توسعه است و انتقال کامل کد اصلی Floot هنوز انجام نشده است.
